Build, select, render, and encode

Run from the project root. Substitute the installed Blender executable for blender. On PowerShell, prefix a quoted executable path with &. Each new build uses a new revision or tag; existing checkpoint directories are preserved.

blender --background --factory-startup --python-exit-code 1 --python build_scene.py -- --stage final --revision 2 --render none --device auto
blender --background --factory-startup --python-exit-code 1 --python render_saved.py -- --scene stages/final-v02/final-v02.blend --output final-frames/final-v02 --device auto --plan
blender --background --factory-startup --python-exit-code 1 --python render_saved.py -- --scene stages/final-v02/final-v02.blend --output final-frames/final-v02 --device auto
python encode_review.py final-frames/final-v02 papilio-revision-02.mp4 --browser-check

The --plan step opens and inspects the selected file without rendering or writing outputs. Remove --plan for the actual render. Existing complete frames can be resumed only with the same source and effective settings. Corrupt frames, changed settings, or a different scene require a new output directory.

The original final-v01 scene remains usable with the same explicit --scene argument. Do not run a rebuild into its existing checkpoint directory.

Requirements and device selection

Core construction and rendering use Blender’s bundled Python and the standard library. Encoding requires FFmpeg and ffprobe on PATH. For browser verification and the historical review-image helpers, install the recorded versions with python -m pip install -r requirements-review.txt. Browser checks default to installed Microsoft Edge; --browser-channel chromium selects a Playwright-installed Chromium instead.

--device auto selects an available Cycles backend, preferring OptiX, and falls back to CPU. --device cpu explicitly uses CPU. Explicit unavailable GPU backends fail rather than silently substituting another backend. CPU and automatic OptiX selection were tested on the production Windows installation. Other operating systems and GPU backends remain unverified. Recorded environment.

Audit a new scene

blender --background --factory-startup --python-exit-code 1 --python audit_scene.py -- stages/final-v02/final-v02.blend --output audits/final-v02.json

Framing is checked on every scene frame. Intersection checks sample half-second intervals and cover wing plates against each other and the named body parts. They are an artistic scene screen, not fabrication validation.

Configuration contract

JSON supplies defaults. Only explicitly supplied CLI --res and --samples values override it. Unknown keys, invalid types, invalid dimensions, and nonclosing active cycle periods fail before a checkpoint is created. Keep absolute M/C/Z commands when editing the supplied SVG; make_profiles.py regenerates the original contours.
