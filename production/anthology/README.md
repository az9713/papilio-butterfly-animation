# Ten films from the Getty AAT board

Production brief approved in chat: ten new films, each 12–16 seconds at 1280×720 and 24 fps, using editable SVG inputs, Blender, and ElevenLabs music and audio. The accepted Butterfly and Tooth films remain unchanged.

Selected concepts: 1, 3, 4, 7, 9, 15, 19, 25, 28 and 30. Every selection originally received an Appearance forecast of 4. Selection maximizes differences in material, visual mechanism, scale and emotional register rather than treating forecast scores as observed quality.

Each project contains its brief, SVG inputs, Blender scene, build instructions, soundtrack stems, generation receipts, preview iterations, final film and evidence-based assessment. The source scripts read the SVG inputs directly. Animation is baked from the scene builder's labeled story sections. Signature sound cue times are recorded separately and aligned with those actions.

Stages: source and storyboard, low-resolution preview, visual repair, full render, ElevenLabs mix, encoded playback and source-package verification, publication. A generated preview is a development artifact until its staging and delivery checks pass.

The ten shorts condense the original pitches to one visible causal event and payoff. Each project brief records the adaptation. New films use authored vector and procedural 3D construction. GPT Image and fal.ai are not required for this batch.
