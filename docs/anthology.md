# Ten SVG and Blender films

Ten fourteen-second miniature films were selected from the thirty-concept board for visual range. Each selected concept originally received an Appearance forecast of 4. Finished-film scores below evaluate what was actually built.

## Production and evidence

Each project contains a direct SVG input, fourteen-second Blender animation, original ElevenLabs music and sound, retained stems, a standalone source ZIP, preview comparisons and its own README. The new films use authored vector and procedural 3D construction. GPT Image and fal.ai were not used for this batch. [Production journey and repairs](../production/anthology/journey.md).

The builders preserve editable geometry and bake animation into the saved scenes. SVG controls form, while labeled builder sections define event timing. Signature audio cues have explicit start times. JSON files declare the format, seed and brief. These are stylized miniature adaptations, with their differences from the original pitches stated in each player.

## Rubric assessment

Order is Intent / Appearance / Motion / Delivery / Editability, on the existing 0–4 scale. This author-informed review does not establish fresh-viewer understanding or audience acceptance. Delivery and Editability scores are supported by the final per-project playback and extracted-package receipts.

| --- | --- | --- |
| #1 [The Whale in Berth Six](../projects/whale-in-berth-six/) | 3 / 3 / 3 / 3 / 3 | Crane modeling is abstract. A human surveyor and a stronger sense of real dock scale would deepen the original discovery. |

| #7 [Dress Code for a Peacock](../projects/dress-code-for-a-peacock/) | 3 / 3 / 3 / 3 / 3 | The verdicts appear as symbols. Hand pinning, facial reactions and a richer comic pause would improve performance. |
| #9 [His Excellency the Spill](../projects/his-excellency-the-spill/) | 2 / 3 / 2 / 3 / 3 | The minister reaction and fourth reflection chin are omitted. A fluid surface and a clearer reaction remain the strongest improvements. |
| #15 [The Last Passage for the Bronze](../projects/last-passage-for-the-bronze/) | 3 / 3 / 3 / 3 / 3 | This is a stylized kinematic cutaway. It does not simulate casting flow, trapped gas or thermal solidification. |
| #19 [The Seat Facing Backwards](../projects/seat-facing-backwards/) | 2 / 3 / 3 / 3 / 3 | The original emotional backstory is not established. A portrait, empty seat or more specific performed gesture could strengthen it. |
| #25 [The Second Tenant](../projects/second-tenant/) | 3 / 3 / 3 / 3 / 3 | The film is lenticular-inspired staging, not a calculated interlaced optical print. Adult reactions and genuinely view-selected imagery would deepen it. |
| #28 [A Letter Wide Enough to Wear](../projects/letter-wide-enough-to-wear/) | 3 / 3 / 3 / 3 / 3 | The short uses an illustrative woven panel with reverse letter contours. It does not generate a manufacturable Jacquard draft. Factory censorship context is omitted. |
| #30 [Water for the Last Balcony](../projects/water-for-last-balcony/) | 3 / 3 / 3 / 3 / 3 | Flow is animated along a declared path rather than numerically simulated. More nuanced hands, body reactions and bird articulation would improve acting. |

The strongest material and optical payoffs are Whale, Cyanotype, Astrolabe, Peacock and the woven reversal. The two weakest story adaptations are Marbling and Panorama. A concept forecast of 4 does not imply a finished artifact must receive 4. The original Butterfly and accepted Tooth movies remain unchanged.
